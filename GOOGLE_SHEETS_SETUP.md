# Общее хранилище в Google Таблице

После этой настройки все, кто открывает страницу (даже на разных устройствах), будут
читать и сохранять одни и те же товары — вместо того, чтобы каждый видел только
свою локальную копию в браузере.

Все товары лежат в ОДНОЙ таблице, но у каждого есть поле «Категория»
(часы / конструктор 1 / конструктор 2 / без категории). Вкладки над списком
товаров («Все», «Часы», «Конструктор 1», «Конструктор 2») просто фильтруют,
какие товары показать — как раньше работали кнопки-пресеты, только теперь
это переключение вида, а не замена данных.

## 1. Создайте таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → «Создать таблицу».
2. Назовите её как угодно, например «Учёт товаров — данные».

## 2. Вставьте код Apps Script

1. В таблице: **Расширения → Apps Script**.
2. В открывшемся редакторе удалите всё содержимое файла `Code.gs`.
3. Откройте файл `apps-script.gs` (лежит рядом с этой инструкцией в папке проекта),
   скопируйте всё содержимое и вставьте в `Code.gs`.
4. Сохраните проект (значок дискеты или Ctrl/Cmd+S).

## 3. Разверните как веб-приложение

1. Кнопка **Развернуть → Новое развёртывание**.
2. Рядом с «Выберите тип» нажмите ⚙ и выберите **Веб-приложение**.
3. Настройки:
   - **Выполнять как:** Я (ваш аккаунт)
   - **У кого есть доступ:** Все
4. Нажмите **Развернуть**.
5. Google попросит авторизовать скрипт — это ваш собственный код, поэтому
   нажмите «Дополнительно» → «Перейти к проекту (небезопасно)» → «Разрешить».
6. Скопируйте **URL веб-приложения** — он выглядит как
   `https://script.google.com/macros/s/AKfycb.../exec`.

## 4. Подключите URL к сайту

1. Откройте `index.html`.
2. Найдите строку:
   ```js
   const SHEET_API_URL='';
   ```
3. Вставьте туда скопированный URL:
   ```js
   const SHEET_API_URL='https://script.google.com/macros/s/AKfycb.../exec';
   ```
4. Сохраните, закоммитьте и запушьте изменения в GitHub.

Готово. Пока `SHEET_API_URL` пустой, сайт работает как раньше — каждый браузер
хранит свою копию локально. После вставки ссылки в правом верхнем углу страницы
появится статус синхронизации («✅ Сохранено в таблице» / «⚠ Не удалось
синхронизировать»), а кнопка «🔄 Обновить» подтягивает последние данные из
таблицы.

## 5. Наполните таблицу текущими товарами (готовые файлы для вставки)

Рядом с этой инструкцией лежат `items_seed.csv` и `settings_seed.csv` — это все
товары из `clock.json`, `constructor1.json` и `constructor2.json`, собранные в
одну таблицу, плюс текущие курсы/коэффициент. Их можно сразу загрузить,
ничего не вставляя вручную по одному товару.

1. Откройте `exec`-ссылку (та же, что вставили в `SHEET_API_URL`) один раз в
   браузере — это создаст в таблице пустые листы `items` и `settings` с
   нужными заголовками столбцов.
2. В Google Таблице откройте лист **items**.
3. **Файл → Импорт → Загрузка** → выберите `items_seed.csv`.
4. В настройках импорта укажите **«Заменить текущий лист»** → Импортировать.
5. То же самое повторите для листа **settings** и файла `settings_seed.csv`.
6. Обновите страницу сайта (или нажмите «🔄 Обновить») — товары подтянутся из
   таблицы.

Если хотите вставить вручную вместо импорта: откройте CSV-файл в блокноте,
выделите всё, скопируйте и вставьте в ячейку A1 нужного листа — Google
Таблицы сами разложат данные по столбцам.

## Важно знать

- Механизм устроен как в приложении triops_uchet: каждое действие (добавить/
  изменить/удалить товар, изменить курсы) отправляется отдельным запросом и
  меняет только ОДНУ строку в таблице — весь лист `items` целиком никогда не
  перезаписывается. Именно полная перезапись листа при каждом сохранении
  раньше приводила к тому, что данные периодически «обнулялись». Экран
  обновляется сразу (оптимистично), а если запрос к серверу не удался —
  изменение откатывается назад и показывается предупреждение.
- Если два человека одновременно редактируют **один и тот же** товар —
  победит тот, кто сохранил последним. Изменения **разных** товаров друг
  другу не мешают.
- Страница загружает данные из таблицы один раз при открытии, плюс по кнопке
  «🔄 Обновить» — автообновления в фоне нет (это тоже как в triops_uchet),
  так что если правки вносили с другого устройства, обновите страницу или
  нажмите «🔄 Обновить», чтобы их увидеть.
- Кнопки «Часы» / «Конструктор 1» / «Конструктор 2» и импорт JSON — это
  единственное **массовое** изменение: они заменяют весь список товаров в
  таблице (точечными запросами добавить/обновить/удалить по каждому товару),
  поэтому перед этим действием сайт всегда просит подтверждения.
- `APP_KEY` в `apps-script.gs` и `SHEET_API_KEY` в `index.html` должны
  совпадать буква в букву — это простая защита от посторонних, которые
  случайно узнают ссылку `/exec`. Можно сменить на свою строку в обоих
  файлах сразу.
- Товары можно посмотреть и поправить прямо в таблице как обычные строки —
  удобно для резервных копий (просто скопируйте лист).
- Если видите «⚠ Не удалось синхронизировать» или всплывающее окно с
  ошибкой — откройте консоль разработчика в браузере (F12) на странице
  сайта, там будет точный текст ошибки (в т.ч. если ключи не совпали —
  будет «bad key»).
- Если позже меняете код в `apps-script.gs`, не создавайте новое развёртывание
  заново (это меняет URL) — используйте **Развернуть → Управление
  развёртываниями → ✏️ → Новая версия**, тогда ссылка останется прежней.
